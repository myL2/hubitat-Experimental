# HOBEIAN ZG-303Z — Zigbee soil moisture sensor (capacitive)

Findings from pairing one unit on Hubitat (C-8 Pro, platform 2.5.2) on 2026-10-10.
Hubitat device: **271 "HOBEIAN ZG-303Z SMS"**.

## Device

| | |
|---|---|
| Model / manufacturer | `ZG-303Z` / `HOBEIAN` (reports these, not `TS0601` / `_TZE200_…`) |
| Firmware | application 95, software build `0130072025` |
| Power | battery (3.0 V); sleepy end device |
| Probe | circuit-board (capacitive) probe; air temperature / humidity sensor in the head |
| In clusters | `0000, 0003, EF00, 0402, 0405, 0001` |
| Out clusters | `0003` |

## Driver

myL2 **"Tuya Zigbee Soil Sensor"** (`drivers/Tuya/TuyaZigbeeSoilSensor.groovy`), shared with the QT-07S.
kkossev's *Tuya Temperature Humidity Illuminance LCD Display with a Clock* (2.1.2+) can be forced to its
`TS0601_Soil_Coolo` group, but does not auto-detect this manufacturer.

## Tuya data points (Zigbee2MQTT: COOLO CS-201Z map, which matches `zigbeeModel ZG-303Z`)

| DP | Meaning | Values seen |
|---|---|---|
| 3 | soil moisture % | 0 (air), 42–62 (soil), 100 (after watering) |
| 5 | temperature ×10 | 239 = 23.9 °C |
| 109 | **air** humidity % | 84–93 (reads high, see below) |
| 15 | battery % | 100 |
| 106 | dry alarm | not seen yet |
| 9 | temperature unit (0 °C, 1 °F) | 0 |
| 104 | temperature calibration ×10 (−2.0…2.0 °C) | 0 |
| 105 | humidity calibration (−30…30 %) | 0 |
| 102 | soil calibration (−30…30 %) | 0 |
| 111 | temperature / humidity sampling (5–3600 s) | 30 |
| 112 | soil sampling (5–3600 s) | 30 |
| 110 | soil dryness warning threshold (0–100 %) | 20 |

Standard clusters: `0402:0x0000` temperature ×100 (same as DP 5); **`0405:0x0000` carries the SOIL moisture
×100** (matched DP 3 exactly at every report: 51, 54, 56, 58, 60), not air humidity; `0001` battery % and 3.0 V.

## Findings

- Settings are read back from the sensor at each data query; the driver keeps the preferences in sync.
- Default sampling of 30 s is very frequent for a battery device; 1800 s is more sensible for plants.
- Air humidity read 84–93 % even before planting — higher than typical indoor air; check against another
  sensor and use the humidity calibration.
- Capacitive probe: rises slowly after insertion (51 → 62 % over ~10 min), steady (±2 %) once settled.
