# Heiman SOS button (Tuya TS0211)

Findings from pairing and testing one unit on Hubitat (C-8 Pro, platform 2.5.2) on 2026-10-04.
Hubitat device: **261 "Test Heiman SOS button"**.

## Device

| | |
|---|---|
| Brand | Heiman (Tuya OEM) |
| Zigbee model / manufacturer | `TS0211` / `_TZ1800_rrv4u5fr` |
| Firmware | application `0x44` |
| Power | battery, 3 V (2.8 V when paired); sleepy end device |
| Endpoints | `01` only |
| In clusters | `0000, 0001, 0003, 0020, 0500, 0B05` |
| Out clusters | `0019` (OTA) |
| IAS zone type | `0x0115` (key fob) |

Zigbee2MQTT knows `TS0211` only as the Lidl HG06668 doorbell button (other manufacturer ids), also IAS zone based.

## Driver

myL2 **"Tuya Zigbee SOS Button"** (`drivers/Tuya/TuyaZigbeeSosButton.groovy`). No built-in driver matched: the hub
first picked *Generic Zigbee Moisture Sensor (no temp)*.

- Every press = `pushed 1`. Option *Detect double press*: two presses within 0.6 s = `doubleTapped 1` (single
  presses are then reported 0.6 s late).
- Battery from voltage `0x0001:0x0020` (2.1–3.0 V = 0–100 %); `batteryLow` from zone status bit 3.
- Setup: change the type, click **Configure**, press the button immediately (writes the hub as IAS CIE, enrols,
  configures battery reporting).

## Findings

- **A press is one IAS zone status change notification, `zone status 0x0001`** (alarm1). Nothing for hold or
  release, no "clear" status afterwards, no repeats (unlike the TS0215 remote, see [TS0215.md](TS0215.md)).
- **Double press** arrives as two notifications 0.14–0.41 s apart.
- The same press is occasionally delivered 2–3 times within ~10 ms; the driver ignores presses < 80 ms apart.
- **Enrol loop at pairing:** with the Generic Zigbee Moisture Sensor driver the button sent an enrol request every
  2 s for ~25 s even though it acknowledged each enrol response (default response, status success). With this
  driver's Configure it enrolled after one request.
- Hubitat's `zigbee.parseZoneStatusChange()` did not report alarm1 for these messages; the driver reads the bitmap
  from the description string.
